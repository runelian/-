# ★ SNAKE // КРАСНАЯ АРЕНА

> Советская аркадная RPG-змейка в одном HTML-файле. Ешь энергокристаллы, повышай квалификацию, модернизируй машину и выполняй норматив.

## Что уже есть

- **RPG-прогрессия:** опыт, уровни и звания оператора.
- **Прокачка:** скорость, ускорение и броня.
- **Экономика:** энергокристаллы используются как внутриигровая валюта.
- **Автосохранение:** прогресс хранится в браузере через `localStorage`.
- **Нормативная арена:** очки, длина змейки, скорость и специальные XP-кристаллы.
- **Управление:** стрелки, WASD, пробел для паузы, R для новой смены.
- **Мобильный режим:** сенсорное управление свайпами.
- **Без зависимостей:** игра работает прямо из `index.html`.

## Запуск

Откройте `index.html` в браузере.

Для публикации через GitHub Pages достаточно использовать `index.html` в корне репозитория и выбрать ветку `main` в настройках Pages.

## Игровая модель

Уровень повышается за XP. С каждой ступенью растёт множитель опыта. В цехе модернизации за энергокристаллы доступны три направления:

| Модернизация | Эффект |
|---|---|
| **Форсаж** | увеличивает базовую скорость |
| **Ускоритель** | усиливает прирост скорости во время длинной серии |
| **Броня** | добавляет запас на столкновения |

Стоимость улучшений растёт по мере прокачки, поэтому экономика не сводится к бесконечной покупке одной характеристики.
